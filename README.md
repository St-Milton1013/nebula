# nebula

New codie iteration — a modular, multi-deck CEDH deck audit tool.

- **Purpose:** run audits on multiple CEDH decks; each audit returns useful info on cards, deckbuilding, and meta.
- **Structure:** `NEBULA-CHECKLIST.md` is the working plan (wayfinder map + running checklist). It is the only tracked file for now.
- **Scope:** planning stage. Code for the audit modules is written in separate chats; this repo owns the roadmap and tracking.

See `NEBULA-CHECKLIST.md` for the full plan.
